# BLU Analytics Suite — UIN Kiai Ageng Muhammad Besari Ponorogo

Dashboard analisis strategis kelembagaan untuk transformasi menuju Badan Layanan Umum (BLU).

## 🟢 Halaman Publik

| Halaman | Deskripsi |
|---------|-----------|
| [Dashboard PTKIN](index.html) | Peta interaktif 15 PTKIN Jawa dengan radar chart perbandingan |
| [Dashboard SINTA](sinta.html) | Analisis riset & publikasi 16 PTKIN dari data SINTA |

## 🔒 Halaman Internal

Halaman internal dilindungi oleh Cloudflare Access (login email OTP).
Akses terbatas untuk pengelola institusi.

## Teknologi

- HTML5 / CSS3 / JavaScript (Vanilla)
- Chart.js — Visualisasi data
- Leaflet.js — Peta interaktif
- html2canvas — Ekspor PNG
- jsPDF — Ekspor PDF
- Cloudflare Pages — Hosting
- Cloudflare Access — Autentikasi
